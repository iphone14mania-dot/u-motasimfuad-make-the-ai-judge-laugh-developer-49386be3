A tiny Node program that writes one funny single-line excuse a developer gives when code breaks in production to `/output/entry.txt`. It opens with the most worn excuse of all — "It worked on my machine" — and turns it: the machine was a snowflake running the old database, the old config, and the dev's own uncommitted fix. 108 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
